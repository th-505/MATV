# 05.01 — الحفظ والإزالة محليًا

**المهمة الرئيسية:** 05 — مكتبة الاستكشاف الخاصة
**الحالة:** جزئي
**تاريخ المراجعة:** 2026-10-24

## النطاق
موجود في localStorage داخل المتصفح، دون مزامنة حسابات.

## ما تم
يوجد تنفيذ جزئي موثق في ملفات المهمة الرئيسية القديمة أو كود المشروع، لكنه لم يجتز معايير الإغلاق.

## خطوات التنفيذ والتحقق
1. تحديد الملفات والدوال الفعلية المرتبطة بالمهمة في GitHub.
2. تنفيذ التعديل دون كسر الواجهات الأخرى.
3. اختبار السيناريو الطبيعي والخطأ والتراجع مع حفظ الدليل.
4. تسجيل commit والنتيجة والتاريخ هنا، وتحديث حالة المهمة الرئيسية.

## شروط الإغلاق
- اختبار ناجح قابل للتكرار.
- توثيق commit ونتائج التحقق.
- لا توجد مشكلة مانعة مفتوحة في نطاق المهمة.

## سجل التنفيذ
- 2026-10-24: إنشاء ملف المهمة؛ جزئي.

### تنفيذ 2026-10-24 — خدمة قائمة خاصة قابلة للتخزين
تتوفر `list/save/remove` في `createExplorationLibrary` مع `loadUser/saveUser` محقونين. تُعزل القوائم حسب هوية الخادم، وتُنسخ النتائج لمنع تعديل الحالة بالإشارة. اختبارات مستخدمين اثنين وحذف خاص وكتابات متزامنة ناجحة. لا توجد بعد وصلة HTTP أو adapter Supabase لهذه الخدمة؛ هذا تقدم برمجي جزئي، وليس إثبات مزامنة حية.

### موصل التخزين 2026-10-24
أضيف `server/exploration-store.mjs`: تحقق Bearer فعلي عبر Supabase Auth، عزل الملكية، metadata فقط، tombstones، ومقارنة `sync_revision` لمنع فقد تقدم متزامن. 9 اختبارات موصل ناجحة، و22 مع اختبارات النشاط والمنسق. بوابة التفعيل مغلقة افتراضيًا؛ القيد الحي لا يسمح بعد بـ`kind=exploration`. لا يُستخدم history أو favorite بديلًا. تفاصيل المسارات المطلوبة في `docs/EXPLORATION_STORE_INTEGRATION.md`؛ لم يُعدل app أو واجهة المستخدم.
