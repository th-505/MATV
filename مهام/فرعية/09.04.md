# 09.04 — حماية مفتاح Gemini وإدارة الحصص

**الحالة:** لم يُنفذ.

- حفظ المفتاح في بيئة Render/الخادم فقط؛ لا في GitHub أو JavaScript المتصفح.
- التحقق من وجوده دون طباعة قيمته، وإضافة حدود طلبات وميزانية ومهلات وإعادة محاولات محدودة.
- عند غياب المفتاح أو فشل Gemini: يستمر الفحص التقني ويُسجل «غير مدقق بالذكاء الاصطناعي» دون اعتبار السيرفر موثوقًا تلقائيًا.
- اختبارات منع تسرب المفتاح في API والسجلات والملفات.
