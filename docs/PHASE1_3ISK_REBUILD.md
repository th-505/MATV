# المرحلة 1 — إعادة هيكلة قصة عشق، إصدار 1.0.36 / build 36

## الأقسام المعتمدة

قصة عشق صفحة مستقلة في Flutter للجوال والتلفزيون، وبها هذه الخيارات الأربعة فقط:

| القسم | API ID | صفحة المصدر |
| --- | --- | --- |
| قصة عشق (أحدث الحلقات) | 3isk-latest | https://3iskk.xyz/ |
| جميع المسلسلات (مترجم ومدبلج) | 3isk-turkish | https://3iskk.xyz/w-srs/ |
| مسلسلات مدبلجة (مدبلج فقط) | 3isk-dubbed | https://3iskk.xyz/genre/series-mudablij-121/ |
| جميع الأفلام | 3isk-movies | https://3iskk.xyz/w-mvs/ |

مسار w-hlqat غير مستخدم. بقي معرّف 3isk-turkish متوافقًا مع العملاء السابقين، لكنه يعرض الآن الاسم الصحيح لجميع المسلسلات. تميّز عملية التحليل الحلقة والمسلسل والفيلم، وتسمح مراجع العمل بمسار movies أيضًا. تظهر الحلقات الأخيرة كأعمال قابلة للتشغيل مباشرة.

## التشغيل

يستخرج الخادم رابط HLS/MP4 الفعلي، أو يعيد قرار استخراج خلفي للعميل عند رفض miravd شبكة Render، ويعيد playback_headers؛ ينقل نموذج Flutter الترويسات إلى VideoPlayerController.networkUrl(httpHeaders: ...). لا يُعاد عنوان صفحة المشاهدة أو التضمين بدل الفيديو. عند فشل قصة عشق تُجرى محاولة تجديد واحدة ثم تظهر إعادة المحاولة داخل التطبيق؛ لا يُفتح WebView أو موقع GitHub Pages لقصة عشق.

أُزيل عنوان GitHub Pages الثابت من مشغل Flutter، وأصبح غلاف fallback الخاص بالمصادر الأخرى HTML محليًا بدل الصفحة القديمة التي تعيد 404. ضُبطت مساحة الفيديو لتجنب تجاوز حدود الشاشة. عنوان API الافتراضي أصبح https://matv.onrender.com.

### اختلاف ترويسات المصادر المثبت بالاختبار

- ukrcdn: Referer=https://3iskk.xyz/ مع User-Agent الخاص بالمزود.
- بعض الأفلام تستخدم miravd.com وCDN من s<number>.grzcdn.com. أثبت طلب حي أن Referer=3iskk.xyz يعيد 403، وأن Referer=https://miravd.com/ يعيد 200. لذلك يرسل المشغل الترويسة المناسبة التي يعيدها API، بدل فرض ترويسة تكسر الفيلم.
- يُفك جدول الاستبدال النصي في مشغل miravd دون eval أو تنفيذ JavaScript خارجي. تُقبل نطاقات المشغلات/CDN المحددة فقط وتُرفض الروابط الخادعة.
- روابط ukrcdn تحافظ على expires الفعلي؛ miravd لا يعلن انتهاءً مماثلًا، لذا expires_at له مهلة صلاحية محافظة محليًا قدرها خمس دقائق، وليست ادعاءً بوقت انتهاء توكن المصدر. الكاش ينتهي قبلها بدقيقة. إذا أعاد miravd 403 لشبكة الاستضافة، يجلب العميل الأصلي بيانات المشغل في الخلفية عبر HTTP مع الترويسات، ويفك جدول النص، ثم يمرر رابط CDN إلى المشغل. لا تُفتح الصفحة في واجهة المستخدم ولا تمر بايتات الفيديو عبر Render. لا يُخزّن قرار الاستخراج الخلفي باعتباره رابط بث صالحًا. تغيّر مفتاح كاش التشغيل إلى playback:v2 لمنع إعادة بيانات سابقة بلا ترويسات.

## التحقق

نجح فحص صفحات المصدر الحية: 46 حلقة حديثة، و28 مسلسلًا، و28 مسلسلًا مدبلجًا، و28 فيلمًا في الصفحة الأولى. نجح استخراج الحلقة 187 من مسلسل المنظمة وفيلم الرسائل الصفراء، وتحميل مانيفست كل منهما مع ترويساته (200).

تغطّي اختبارات Node التصنيفات الأربعة، المراجع، الجلسة، التحويلات، استخراج الحلقة والفيلم، فك جدول النص، الكاش وتجديده، وHTTP/CORS. تشمل اختبارات Flutter:

- قائمة الأقسام الأربعة فقط وتغييرها إلى الأفلام عبر واجهة المستخدم.
- وصول URL وReferer وUser-Agent الفعلية إلى واجهة المشغل الأصلي.
- فشل أصلي محاكى: تجديد مرة واحدة بلا WebView أو تحويل GitHub.
- منع النطاقات غير الموثوقة والروابط المنتهية، واحتفاظ النموذج بالترويسات المسموحة فقط.

للفحص الحي بعد النشر، يشغّل `node --use-env-proxy scripts/phase1_3isk_validation.mjs https://matv.onrender.com` عملًا من كل قسم، بما فيه المانيفست وأول مقطع باستخدام الترويسات، دون تسجيل روابط التوكن.

هذه اختبارات آلية وعبر الشبكة، وليست ادعاءً بتثبيت الحزم الجديدة على أجهزة المستخدم الفعلية. اختبار Safari/4G السابق يخص ukrcdn؛ لا يُعمم على miravd. اختبارات CORS وFlutter Web الكاملة ضمن المرحلة 5، والفحص الشامل للأجهزة ضمن المرحلة 6. لا تبدأ المرحلة 2 ضمن هذا التسليم.

محركات المباريات والأخبار وكاشط أكوام لم تتغير في هذه المرحلة.

نُشر commit `c96b5b303bfbcb15cce11a9f690b6abaca0bb542` على Render بحالة live. نجحت فحوص Node والتحليل، و90 اختبار Flutter على الموبايل و90 على TV. نجح فحص حي لعمل من كل قسم عبر API ثم المانيفست والمقطع (200/206)، وأُعيد الفحص باستخدام كود AlQahtaniApi وmiravdMediaUrl الفعلي في Dart؛ نجحت الأقسام الأربعة، وكلها انتهت إلى تشغيل direct مع الترويسات المناسبة. يمكن إعادة فحص العميل عبر `dart run tool/phase1_client_smoke.dart` من flutter_app، ويحتفظ التقرير `docs/PHASE1_3ISK_RESULTS.json` بالنتائج دون روابط توكن.
