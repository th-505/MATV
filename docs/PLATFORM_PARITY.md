# توافق منصات T-A-TV

هذا جرد للمصدر وعقد قبول، وليس إعلان إصدار أو شهادة بأن التطبيقات المثبتة تطابق الويب. تاريخ الجرد: 2026-10-24. العقد المقروء آليًا في [platform-parity.json](platform-parity.json).

## حقيقة النسخ الموجودة

| الهدف | مصدر الواجهة | الموجود في المستودع | وصفة البناء | ما لم يثبت |
|---|---|---|---|---|
| الويب الأساسي/PWA | `index.html` و`web/` | HTML وmanifest وservice worker | تقديم ملفات ثابتة | حالة النشر وتجربة المتصفح الحية في هذا الجرد |
| Flutter Web | `flutter_app/lib/` | scaffold ويب، وحزمة قديمة مجمعة في `app/` | `flutter-web.yml` | إعادة بناء الحزمة مع تعديلات الجلسة الحالية |
| أندرويد جوال | `flutter_app/lib/` نفسه | لا يوجد scaffold Android محفوظ؛ يولده Workflow | `mobile-trial.yml` مع `MITV_TARGET=mobile` وARM64 | APK حالي، توقيعه، تثبيته وتجربة الهاتف |
| أندرويد TV | المصدر نفسه | يولد Android ثم يطبق `configure_tv_manifest.py` | `MITV_TARGET=tv` وARMv7 | تجربة الريموت وAPK مثبت |
| آيفون | المصدر نفسه | يولد scaffold iOS | بناء `--no-codesign` ثم IPA غير موقع | التوقيع الخارجي والتثبيت وتجربة iPhone |
| ويندوز | المصدر نفسه | runner/CMake محفوظان في `flutter_app/windows/` | EXE مع ZIP وInno Setup في Workflow | حزمة جديدة وتجربة تثبيت Windows |
| macOS | المصدر نفسه | scaffold مولد أثناء Workflow | DMG بتوقيع ad-hoc بلا notarization | حزمة جديدة وتجربة Mac |
| Linux | المصدر المشترك يحتوي تمييز Linux كحاسوب | لا scaffold Linux ولا job بناء Linux | غير مهيأ | لا يوجد إصدار Linux مثبت أو قابل للادعاء بأنه جاهز |

هناك ستة أهداف في وصفة الإصدار القديمة عند احتساب Web وAndroid Mobile وTV وiOS وWindows وmacOS. وجود تمييز Linux في Dart لا ينشئ هدف إصدار سابعًا تلقائيًا. `app/` مخرجات Flutter Web وليس مشروع Flutter المصدر، وملفات `app/main.dart.js` لا تُعدل يدويًا.

عند الجرد لا توجد ملفات APK/IPA/EXE/DMG/ZIP إصدار داخل شجرة المصدر. `app/source-manifest.json` يسجل حزمة Web تاريخية بالإصدار 1.0.44/build 44 وcommit `11981ccf141c0f6f3aa9721119494a5754dea5dc` وهو دليل منشأ معلن للحزمة القديمة؛ ليس إثبات توافقها مع تعديلات اليوم. عنوانا `https://th-505.github.io/MATV/` و`/MATV/app/` ومسار API في Render واردة في التهيئة؛ لا نعتبرها نشرًا متحققًا دون فحص مستقل.

## العقد المشترك المطلوب

ترتيب الوجهات ثابت: `home → movies → series → anime → turkish → search → live → favorites → settings`. الاسم T-A-TV، واللغة عربية وRTL. `#explore` في الويب اسم قديم يفتح `search` مع توسيع البحث المتقدم، وتبقى تفاصيل العمل والمشغل مستقلين عن هذه القائمة.

الشريط الجانبي على اليمين دائم عند عرض 900 بكسل فأكثر، وعلى TV والحاسوب الأصلي. في العرض الضيق يفتح درج يمين بزر قائمة عائم. لا شريط علوي ولا تنقل سفلي. البحث صفحة مستقلة، والاستكشاف إعداد متقدم داخل البحث. تغيير الوجهة يغلق الدرج؛ إغلاقه بلوحة المفاتيح يعيد التركيز إلى زر فتحه. عناصر الريموت تحتاج مؤشر تركيز ظاهر ومسار رجوع واضح.

ألوان العقد: خلفية `#07090b`، سطح `#0d1117`، سطح مرتفع `#121824`، ذهبي `#e8bd75`، ذهبي فاتح `#f7d594`، داكن `#b88b3e`، نص `#ffffff` وثانوي `#94a3b8`. المصدران التنفيذيان للعقد هما `web/core/ui-contract.js` و`flutter_app/lib/src/ui_contract.dart`. التطابق بينهما يثبت ثوابت المصدر فقط؛ اللقطات البصرية وإمكانية الوصول تحتاج قبولًا منفصلًا.

المحتوى الوصفي من TMDB، والبحث عن روابط التشغيل في الخلفية. الاستكشاف يثبت المصدر المختار دون انتقال صامت. بيانات المفضلة خاصة بالمستخدم، والنشاط الفعلي يجدد صلاحية روابط المشاهدة لمدة سبعة أيام. MP4 وHLS هما أساس قبول المشغل، وiframe لا يعد رابط فيديو مباشرًا. المتصفح تحكمه قيود CORS والكوودكات؛ مشاركة المصدر لا تزيل فروق المنصات. مفاتيح Gemini ومفاتيح صلاحيات Supabase تبقى بالخادم.

## قبول كل منصة قبل إعلان التطابق

| الحالة | القبول المطلوب | دليل الإغلاق |
|---|---|---|
| NAV-DESKTOP | 1440px: شريط يمين، كل وجهة تفتح محتواها، لوحة مفاتيح دون فقد التركيز | اختبار متصفح ولقطة |
| NAV-MOBILE | 390px: زر عائم، درج يمين، اختيار البحث يغلقه، الرجوع/Escape يعيد التركيز | متصفح جوال وهاتف أصلي |
| NAV-TV | D-pad وSelect فقط: كل وجهة والمشغل قابلان للوصول والرجوع | جهاز TV أو محاكي مع سجل إدخال |
| SEARCH-OWN-PAGE | البحث وجهة مستقلة، والاستكشاف داخل قسم متقدم قابل للفتح | تفاعل مرئي في Web وFlutter |
| EXPLORE-PIN | فشل المصدر المختار لا يعرض نتائج مصدر آخر | fixture واختبار UI |
| PLAYER-RESUME | MP4 وHLS مصرحان، تبديل صريح، حفظ الموسم والحلقة والزمن، رفض iframe كمباشر | متصفح وجهاز لكل عائلة |
| THEME-RTL | ألوان موحدة، RTL، لا overflow في الجوال، تركيز واضح | لقطات مقاسات متعددة |

## التحقق والحدود

شغل `python3 scripts/platform_parity_test.py` لفحص عقد المصدر ومساراته ووصفات البناء ومشغل Flutter والـTV وتحذير الحزمة التاريخية. الفحص يقارن القيم المطلوبة بمصدري Web وDart ولا يكتفي بعد عدد الملفات. لا يشغّل Flutter SDK ولا ينشئ حزمًا ولا يتحقق من متجر أو جهاز فعلي.

قبل إعلان إصدار موحد يجب بناء كل هدف من commit واحد وبـAPI واحد، وإرفاق manifest منشأ وSHA-256 وفحص architecture ثم تنفيذ حالات القبول. فشل أو غياب هدف يظل ظاهرًا؛ لا يُستبدل بإعلان أن «كل النسخ جاهزة». المهمة 12 لا تغلق بهذه الوثائق أو بنجاح فحص المصدر وحده.

نتيجة التحقق المحلي لهذه الإضافة: **8 اختبارات ناجحة**. تشمل تنفيذ resolver الويب، مقارنة العقد بين JS وDart، تكامل وجهات DOM، مسار البحث في Flutter، تهيئة API في أوامر البناء، وتحويل TV manifest مرتين للتحقق من ثباته، وكاتب سجل منشأ الحزمة مع رفض عنوان HTTP. لا تعني هذه النتائج أن SDK بنى النسخ أو أن أي حزمة قد ثُبتت.
