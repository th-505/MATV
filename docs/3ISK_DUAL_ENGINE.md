# قصة عشق: استخراج ثنائي — 1.0.38 / build 38

يقرأ السيرفر iframe الفعلي داخل Wrapper ويتحقق من نطاقه ومساره قبل التفريع. الأقسام الأربعة هي أحدث الحلقات، جميع المسلسلات، المدبلج، وجميع الأفلام؛ w-hlqat مستبعد.

- ukrcdn: يستخرج السيرفر رابط HLS/MP4، ويعيد stream_url وheaders مع الأسماء السابقة المتوافقة. طلب صفحة المشغل يستخدم Referer=https://3iskk.xyz/؛ الفيديو يستخدم أصل CDN المختبر.
- miravd: يعيد السيرفر بيانات المشغل فورًا، دون محاولة الاتصال بـmiravd من Render. يجلب تطبيق Dart الصفحة بترويسة Wrapper كاملة، ويفك Dean Edwards Packer بالأساس 2–62 دون eval. يمرر الرابط المباشر إلى VideoPlayer مع Referer=https://miravd.com/ وUser-Agent.

مسارا /api/v1/3isk/resolve و/api/cinema/details يستخدمان الاستراتيجية نفسها. مثال بيانات miravd:

```json
{
  "status": "success",
  "player_type": "miravd",
  "extractor": "miravd",
  "playback_mode": "client_resolve",
  "iframe_url": "https://miravd.com/embed-fixture.html",
  "wrapper_url": "https://3iskk.xyz/embed/1/12345/1/",
  "resolver_url": "https://miravd.com/embed-fixture.html",
  "resolver_headers": {
    "Referer": "https://3iskk.xyz/embed/1/12345/1/",
    "User-Agent": "Mozilla/5.0 ..."
  },
  "download_available": false
}
```

العناوين أمثلة. resolver_url يحافظ على توافق العملاء السابقين، ويقبل Dart iframe_url أيضًا. HTML لا يدخل المشغل الأصلي ولا يفتح التطبيق متصفحًا. تُرفض النطاقات الخادعة والتحويلات إلى نطاق آخر، ويُحدد حجم HTML ووقت الطلب. يظل فك miravd الخادمي متاحًا داخل المزود للاختبارات الصريحة فقط؛ ليس مسار API الافتراضي.

الكاش v4 يمنع استخدام نتائج الاستراتيجية السابقة. لا تُخزن بيانات client_resolve كرابط بث صالح، ولا تُخزن روابط miravd المستخرجة من جهاز المستخدم على السيرفر. صلاحية العميل المحلية القصيرة خمس دقائق تقدير للتجديد وليست وقت انتهاء مضمونًا من المصدر. يُجدد المصدر مرة عند فشل التشغيل.

اختبار Node HTTP حي داخل البيئة نجح للمحركين: API 200، manifest 200، أول مقطع 206. اختبار عدم الاتصال بمضيف miravd من السيرفر يغطي المسار الافتراضي، واختبار Flutter يغطي تحويل iframe_url إلى رابط مباشر مع Wrapper ثم Referer الخاص بالفيديو. اختبارات الإنتاج وDart محفوظة في التقرير المصاحب عند اكتمال النشر.

لا تُضاف خوادم أو بروكسي فيديو. تجربة العميل في هذه البيئة لا تمثل اختبار تركيب فعلي على هاتف أو TV، ولا تضمن قبول كل شبكة سكنية. Flutter Web قد يحتاج معالجة CORS في المرحلة 5؛ عنوان IP وحده لا يحل قيود المتصفح.

وظيفة Supabase التجريبية القديمة غير مربوطة بالمشروع، وحماية JWT لها مفعلة. كاش Supabase يتطلب مفتاح sb_secret_ صالحًا بعد تعطيل المفاتيح القديمة؛ تعطل الكاش الدائم لا يوقف التشغيل، ويستخدم الخادم الذاكرة مؤقتًا. ملفات أكوام ومحركات المباريات والأخبار لم تتغير. لم تبدأ المرحلة 2.
