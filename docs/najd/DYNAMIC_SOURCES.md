# مصادر نجد الديناميكية

المستودع الحالي: https://github.com/th-505/NajdTV

## أين تضاف المصادر؟

- القواشط المستقلة: `server/scrapers/sites/<provider>.mjs`.
- تسجيل القاشط مرة واحدة على السيرفر: `server/scrapers/registry.mjs`.
- قائمة التطبيق والبحث: `/api/v1/explore/sources`، وقائمة القدرات الكاملة: `/api/v1/sources`.
- التصفح المستقل: `/api/v1/browser/sources` و`/api/v1/browser/catalog`.
- لوحة متابعة السيرفر: https://najdtv.onrender.com/admin (البيانات الإدارية تتطلب صلاحية الإدارة).

إضافة قاشط جديد إلى GitHub ونشر تحديث السيرفر الحالي تكفي لظهوره في النسخ التي تتضمن دعم المصادر الديناميكية. لا يلزم إنشاء سيرفر آخر، ولا بناء التطبيق مجددًا لكل مصدر. جميع أهداف Flutter (iOS، Android mobile/TV، Windows، macOS وWeb) تستخدم نفس عميل المصادر. النسخ المثبتة الأقدم التي تتضمن قوائم ثابتة تحتاج تحديثًا واحدًا لهذه الآلية؛ لا يمكن تعديل الشيفرة الأصلية لتطبيق مثبت عن بعد.

تحديث رابط أو محددات مصدر مسجل يمكن أن يستخدم إعدادات القواشط القائمة في `najd_provider_config`، التي يحدّثها السيرفر دوريًا كل 30 ثانية عند تفعيل مخزن الحصاد. ذلك لا يجعل رابط أي موقع قاشطًا صالحًا تلقائيًا. موقع جديد ذو بنية مختلفة يحتاج قاشطًا واختبارات ونشر شيفرة السيرفر. لا ينزّل التطبيق شيفرة تنفيذية للقواشط، ولا ينفّذ JavaScript من GitHub.

التحقق من اسم المصدر والرابط وDNS والتحويلات وأرقام الحلقات يحدث على السيرفر؛ التطبيق يتحقق من صيغة المرجع فقط ويستخدم مسارات API ثابتة. لا تُرسل روابط الفيديو الموقعة أو المفاتيح إلى التطبيق ضمن قائمة القدرات. تظل معرّفات المصادر السابقة مستقرة للمحفوظات والسجل.

## برستيج

- المعرف: `brstej`، رمز السيرفرات: `BR`، نطاق الرصد: https://brstejj.beer/home03.
- قاشط مستقل للبحث، الرئيسية، الأقسام، الأفلام، المسلسلات، الفهرس والسيرفرات، مع 24 قسمًا مرصودًا.
- البحث المرصود: `/search.php?keywords=...`، مسلسل: `/series1.php?id=...`، حلقة/فيلم: `/video.php?vid=...`، مشغل: `/play.php?vid=...`.
- عينة المدينة البعيدة أعطت 352 مرجعًا أصليًا موزعًا على 3 مواسم، وأعلى رقم 351. البدائل لا تصبح حلقات مصطنعة، ولا يُقص الفهرس عند 60 أو 70.
- فحص حي منفصل لفيلم ومسلسل آخر (11 حلقة) أكد حاويتين HLS؛ لا يمثل ذلك شهادة تشغيل كاملة على جهاز فعلي.

## التوافق

يتحقق اختبار `flutter_app/test/dynamic_provider_test.dart` من اسم مصدر لم يكن مسجلًا في التطبيق: يظهر من استجابة السيرفر، يبحث، يطلب فهرسه ويفتح الحلقة 21 من الموسم الثاني دون الرجوع إلى مسار مزود قديم. يحافظ السيرفر على فحص المضيف والأمان، ولا تُقبل مراجع URL عامة بدل مراجع الأعمال.

## أهواك وتحديث الفهرس — 2.0.1

- القاشط المستقل `ahwak` على https://yam.ahwaktv.net، مع 94 فئة مرصودة. عينة خمسين خمسين تحتوي 15 حلقة فعلية؛ رابط الصورة والعنوان لنفس الحلقة لا يصبح حلقتين.
- البحث `search.php?keywords=...`، فهرس العمل `view-serie.php`، المشاهدة `watch.php?vid=...`، والمشغل `see.php?vid=...`.
- «تحديث الفهرس الآن» يرسل `source_refresh` لمرجع عمل المصدر فقط، ويحتفظ بترقيمه. لا يقبل مرجع TMDB عبر هذا المسار، ولا يعلن اكتمال التحديث عند إدراج المهمة بالطابور.
- قائمة المزودين تتحدث داخل الجلسة عند فتح الاختيار/البحث المتوازي، ويمكن تحديثها يدويًا من متصفح المزود.
- النسخ الجديدة تستخدم https://najdtv.onrender.com. يبقى النطاق القديم لخدمة النسخ السابقة؛ بيانات Supabase ومعرفات المستخدمين لم تُعد تسميتها.
