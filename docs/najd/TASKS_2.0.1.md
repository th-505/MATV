## صورة داخل صورة PiP

- [ ] ربط فعلي بواجهات النظام المتاحة، وإظهار الخيار عند دعم المنصة فقط؛ لا نعد نافذة عائمة داخل التطبيق PiP للنظام.
- [ ] Android: التصريح والدخول والخروج واستمرار التشغيل وتحديث الواجهة وحفظ التقدم.
- [ ] iOS: مسار نظامي يحافظ على التوقيت والتقدم عند الدخول والعودة؛ التحقق من توافق الصيغ وقيود AVKit قبل إعلان الدعم.
- [ ] Web: استخدام PiP للفيديو الحقيقي عند دعم المتصفح؛ عدم عرض زر يعمل شكليًا فقط.
- [ ] اختبارات الجسر وحفظ التوقيت، وبناء الكود الأصلي على المنصات المستهدفة. شهادات التشغيل على أجهزة فعلية غير متاحة هنا ولا يُدّعى إنجازها.
