Najd TV 2.0.3 — Beta 4 · build 203

- Independent Beta provider browsing with source-owned episode indexes, pagination and saved Beta history. Normal Najd browsing retains TMDB metadata and concurrent provider discovery.
- Durable watch checkpoints, resume/restart choice, selected-source index refresh, compact player controls and configurable temporary hold speed.
- Separate server-side source configuration and bounded discovery/index/playback queues. Recovery mode runs requested work without sweeping the accumulated media backlog.
- Android Mobile ARM64, Android TV ARMv7, unsigned iPhone IPA, Windows x64 installer/portable ZIP and macOS DMG.

Website: https://th-505.github.io/NajdTV/
API: https://najdtv.onrender.com

The IPA requires external signing. macOS is ad-hoc signed and not notarized; Windows is not Authenticode signed. Automated source identity, checksums, native architectures, layouts, and Chromium MP4/HLS/PiP fixtures are verified. Physical-device certification and availability of every third-party provider are not claimed. Offline HLS downloading remains unsupported. Native packages use the supplied Thmanyah typography; public Web uses its licensed fallback and supports local font import.
