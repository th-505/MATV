## الأعطال المؤكدة

- الشاشة تبدأ بأول مزود كل مرة، دون حفظ اختيار مستقل؛ ليست مقيدة تقنيًا بماي سيما.
- إنتاج Render: 13 فهرسًا غير فارغ، و7 فشلت، واثنان فارغان غير مؤكدين.
- عينة صورة من كل مزود ذي فهرس (13): صور فعلية ناجحة. فقد الصورة داخل التطبيق أو صفحة التفاصيل ليس غياب رابط دائمًا.
- صفحة MyCima المفحوصة لا تحتوي `.Poster--Single-begin img`، وتحتوي `og:image`؛ محلل التفاصيل يهمل هذا البديل ويعيد صورة فارغة. عينة المسلسل عبر API الإنتاج أكدت `details_poster=false`.
- فهرسة التفاصيل تنتظر 20 ثانية، عامل الحصاد يعالج مهمتين معًا، وSQL claim الحالي يقيد الدفعة إلى 8. رفع عدد المهام وحده إلى 20 لا يصلح فصل مراحل البحث والفهرسة والفيديو.
- البحث المتوازي في Flutter مقيد بستة مزودين، ونافذة المصادر تتوقف عن المتابعة بعد 3 دقائق.
- مسار Browser يخفي سبب فشل القاشط وراء `BROWSER_SOURCE_UNAVAILABLE`، ثم تعرض الواجهة رسالة عامة.
- تسمية الميزة متعارضة: القائمة والإعدادات «بيتا 1»، والصفحة «بيتا 2».
- عينتا إنتاج MyCima: الفيلم تجاوز مهلة فهرسة العميل؛ المسلسل أعاد 25 حلقة دون صورة تفاصيل ثم `DIRECT_MEDIA_NOT_FOUND`.
