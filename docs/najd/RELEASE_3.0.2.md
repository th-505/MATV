# NajdTV v3.0.2

- Episode lists in title details and the player now show groups of 24 observed records. Choose a range directly, move between groups, sort oldest/newest first, or switch between compact squares and horizontal cards. A 1080-episode index has 45 groups without rendering 1080 tiles at once.
- The player opens the current episode's group; season filtering keeps each season independent. Previous/next playback still uses the complete observed queue, not just the visible group. Download actions remain available in title details.
- Grouping does not invent missing episodes, fill numbering gaps, or turn an advertised total into playable links. Additional source-index pages retain the existing load-more action.
- Server repairs include observed Brstej/Laroza/5TV domains, MySeed/ArabSeed cards and search, QFilm's same-video play button, 3ckTV's rotating observed watch bridge and iframe alternatives, EgyDead's work metadata/watch routes, and Anime4Up's TV classification and observed pagination. Najd and Beta adapters remain independently owned.
- Live source/container samples passed for Laroza, ArabSeed, QFilm and 5TV. 3ckTV availability is intermittent. CimaNow film routes remain partially blocked or redirect to unrelated homepages; WitAnime returns a Cloudflare challenge from the test environment; EgyDead Live's old portal now returns VOD. These are not certified as fixed playback services. See PROVIDER_RECOVERY_2026_11_07.md.

Original bundled Thmanyah typography, permanent Android signing key, user identity/library storage and receive-only TV pairing are preserved. The iPhone IPA is unsigned. Physical-device playback, PiP and all source titles are not certified by a successful build.
