# نجد تي في — 81 واجهة وحالة

حزمة واجهات داخل مستودع نجد `th-505/MATV`: **31 شاشة أساسية + 50 إضافة**، اللون الأساسي `#6B46C1`، ومظهران داكن وفاتح. المعرفات الثابتة من `NJD-001` إلى `NJD-081` في `ui/manifest.json`.

## مكان الحزمة ودورها

`design/najd-ui/` هو مرجع التصميم والكود القابل للمعاينة وتسليم المكونات. هذه الإضافة لا تستبدل واجهة Flutter الحالية ولا تربط خدمات البث/التنزيل/قاعدة البيانات. توجد تفاعلات معاينة للبحث في فهرس الشاشات، اختيار الجودة، تعديل قائمة المعاينة، والتنقل بالريموت.

## التشغيل من جذر المستودع

```sh
npm ci --ignore-scripts --prefix design/najd-ui
npm run build --prefix design/najd-ui
npm run check --prefix design/najd-ui
python3 -m http.server 4180 --bind 127.0.0.1
```

افتح `http://127.0.0.1:4180/design/najd-ui/ui/`. هذا خادم تطوير محلي، ولا يضيف مسار نشر عام.

## تشغيل ZIP الجاهز

بعد تنزيل أثر البناء `najd-ui-81` من GitHub Actions، فك الضغط وادخل مجلد `najd-tv` ثم شغّل `python3 -m http.server 4173 --bind 127.0.0.1` وافتح `http://127.0.0.1:4173/ui/`. هذه الحزمة لا تحتاج npm أو إعادة بناء، وتستخدم الخط البديل المفتوح.

## خط ثمانية

تستخدم الأنماط خط `Thmanyah` إذا جُهّز محليًا في `assets/private-fonts/`، مع `Noto Sans Arabic` مرخص ومضمّن كبديل. ملفات ثمانية الأصلية وأرشيف المستخدم لا تدخل Git.

لتجهيز الخط من مجلد المستخدم المفكوك الذي يحتوي `LICENSE.pdf` و`thmanyah typeface/`:

```sh
python3 scripts/prepare_private_fonts.py --source /path/to/Thmanyah-Font-Family
```

الحزمة المقدمة من GitHub تعمل بالخط البديل ما لم تضف ملفاتك الخاصة محليًا؛ لا تسمّى نتيجة البديل اختبارًا لثمانية.

## الفحص والتغليف

```sh
# بعد تشغيل خادم التطوير وتثبيت playwright:
NAJD_UI_BASE_URL=http://127.0.0.1:4180/design/najd-ui/ui/ python3 design/najd-ui/scripts/browser_check.py
# مع الخط الخاص المحضّر محليًا:
NAJD_PRIVATE_FONTS=1 NAJD_UI_BASE_URL=http://127.0.0.1:4180/design/najd-ui/ui/ python3 design/najd-ui/scripts/browser_check.py
python3 design/najd-ui/scripts/package_ui.py
```

فحص المتصفح يحجب الشبكة الخارجية، ويتحقق من الصور والخط في جميع الواجهات ويختبر أربعة مسارات تفاعل. workflow `Najd UI catalogue` يفحص حزمة الـ81 ويرفق ZIP يعمل بالبديل المفتوح، دون خطوط خاصة أو نشر موقع.

أرشيفات المستخدم الأصلية، الصور الكاملة لتصدير الشاشات، ملفات الخط الخاصة، ملفات جلسة Figma ومخرجات التحويل المؤقتة. تضم هذه الحزمة HTML المعالج المطلوب، الصور المنفصلة المستخدمة فيه، وخطط الواجهات وفحوصها فقط.
